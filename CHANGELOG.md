## [0.1.0] - 2026-07-18

### Added

- Synchronous Markdown compilation into a versioned, JSON-compatible narration
  plan and rendering into plain speakable text.
- GitHub Flavored Markdown narration for prose, headings, emphasis, links,
  lists, task items, blockquotes, images, tables, inline code, and code blocks.
- Semantic Python and TypeScript narration for the documented core constructs,
  with deterministic lexical fallback for unsupported or incomplete code.
- Typed deep narration overrides for structural announcements, styles, list
  wording, table modes, operator phrases, callbacks, and explicit subtree skips.
- Custom renderer interface with declared capabilities and ordered diagnostics.
- Equivalent ESM server and self-contained browser entry points, including
  DOM-free worker support.
